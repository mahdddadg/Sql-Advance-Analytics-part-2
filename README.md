SQL Advanced Analytics – Part 2

This repository is the second phase of my SQL analytics project series and focuses on applying advanced SQL techniques to solve real-world business problems and generate actionable insights from sales and customer data.

While Part 1 concentrated on Exploratory Data Analysis (EDA) and understanding the structure, quality, and distribution of the data, Part 2 takes the analysis to a deeper level by building analytical solutions, customer reports, business KPIs, segmentation models, cumulative analysis, and advanced performance tracking using SQL.

Relationship Between Part 1 & Part 2
Part 1 — Exploratory Data Analysis (EDA)

In Part 1, the main objective was to:

Explore the database structure
Understand datasets and relationships
Analyze distributions and trends
Validate data quality
Generate foundational business insights

This phase established the analytical foundation required for more advanced business reporting and decision-making.

Part 2 — Advanced Analytics

In Part 2, the project evolves from exploration into advanced analytical reporting by implementing:

Customer analytics reports
Product performance analysis
Year-over-Year (YOY) analysis
Running totals & moving averages
Customer segmentation
Product segmentation
Revenue contribution analysis
KPI reporting
Ranking analysis using window functions
Reusable SQL views for BI and dashboarding

This phase focuses on transforming raw transactional data into meaningful business intelligence using advanced SQL concepts and analytical thinking.

Project Goal

The goal of this project is to demonstrate how SQL can be used not only for querying data, but also for performing advanced analytics, generating business insights, and building scalable reporting solutions similar to real-world Data Analyst and Business Intelligence workflows.
